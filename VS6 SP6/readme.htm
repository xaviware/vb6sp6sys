Service Pack 6 para Visual Basic 6.0, Visual C++ 6.0 y Visual Source Safe 6.0

El Service Pack 6 para Visual Basic 6.0, Visual C++ 6.0 y Visual Source Safe 6.0 contiene actualizaciones de los siguientes programas:

  • Visual Basic 6.0
  • Visual C++ 6.0
  • Visual Source Safe 6.0

Este Service Pack no contiene correcciones para los siguientes productos, cuyo ciclo de vida útil ha finalizado:

  • Visual InterDev 6.0
  • Visual FoxPro 6.0
  • Visual J++ 6.0

Para obtener más información sobre los ciclos de vida útil de los productos, consulte la página de ciclo de vida útil de Visual Studio. El Service Pack 5, que contiene correcciones para todos los productos antes mencionados, aún se puede encontrar aquí por un tiempo limitado.

Debido a que las actualizaciones de sistemas se distribuyen ahora a través de Windows Update, se han quitado del Service Pack 6 las siguientes:

  • Microsoft Data Access
  • Microsoft Virtual Machine
  • Microsoft Internet Explorer

Para obtener actualizaciones más recientes para componentes de sistemas, visite Windows Update.

Cambios en Visual Basic 6.0

Las principales correcciones para Visual Basic consisten en mejoras de la estabilidad y seguridad realizadas en el tiempo de ejecución de VB. SP6 contribuye a la seguridad y estabilidad. Muchas de estas correcciones ya están incluidas en la versión del tiempo de ejecución de su sistema operativo, como Windows XP y Windows 2000.

Además, a lo largo de los años hemos realizado numerosas correcciones para clientes que han solicitado revisiones del producto VB 6.0. Se puede encontrar una lista actualizada de correcciones aquí.

Cambios en Visual C++ 6.0

Hemos realizado varias mejoras en Visual C++ 6.0 al corregir los errores que nos han señalado nuestros clientes a través del proceso Revisión del Servicio de soporte técnico (Product Support Services Hotfix).

Además, el Processor Pack de Visual C++ (VCPP) se quitó del Service Pack 6. Si tiene el VCPP instalado, la instalación del SP6 lo quitará de su equipo. Si desea continuar utilizando el VCPP, tendrá que quedarse con el SP5 o migrar a Visual Studio 2002 o 2003 (recomendable).

Se puede encontrar una lista actualizada de cambios en Visual C++ 6.0 aquí.

Cambios en Visual Source Safe 6.0

Este Service Pack contiene la versión más reciente ("d") de Visual Source Safe 6.0. Tenga en cuenta que Visual Source Safe 6.0c se comercializó anteriormente como Visual Source Safe 6.0 Service Pack 6. Este nuevo Service Pack reemplaza la versión "c" de Source Safe con la versión "d" que se encuentra en las versiones más recientes de Visual Studio .NET.

Se puede encontrar una lista actualizada de cambios en Visual Source Safe 6.0d aquí.
